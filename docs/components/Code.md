# Code

**Category:** Content  |  **Group:** Code  |  **Port status:** not started

Code marks short inline references such as function names, variables, file
paths, and command-line flags. Use CodeBlock for standalone or multi-line
snippets.

## When to reach for it / when not to

- **Do:** Use Code for short technical terms inside prose, such as a function
  name, prop, file path, or command-line flag.
- **Do:** Set size to 'inherit' when inline code should match the surrounding text
  size and line height.
- **Don't:** Use Code for multi-line or standalone snippets. Use CodeBlock instead so
  readers get appropriate block formatting and syntax support.
- **Don't:** Use Code as an interactive copy or navigation control. Pair it with the
  appropriate Button or Link when an action is required.

## Props

| prop | type | required | default | meaning |
| --- | --- | --- | --- | --- |
| `children` | `ReactNode` | yes | `` | The inline code content. |
| `color` | `'primary' \| 'secondary' \| 'inherit'` | no | `'primary'` | Text color. Use 'inherit' to take the surrounding text color. |
| `size` | `'inherit'` | no | `` | Set to 'inherit' to take the surrounding font size and line height. Omit it to use the code type-scale size. |
| `ref` | `React.Ref<HTMLElement>` | no | `` | Ref forwarded to the semantic code element. |
| `xstyle` | `StyleXStyles` | no | `` | StyleX styles for layout customization. Must be a stylex.create() value, not an inline style object like style={{}}. |
| `className` | `string` | no | `` | CSS class name for the root element. Prefer xstyle for styling. |
| `style` | `CSSProperties` | no | `` | Inline styles for the root element. Prefer xstyle for StyleX-optimized styling. |
| `data-testid` | `string` | no | `` | Test selector for automated testing frameworks. |
