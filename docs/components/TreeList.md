# TreeList

**Category:** Table & List  |  **Group:** TreeList  |  **Port status:** not started

An expandable tree structure for displaying hierarchical data with branch
connector lines. Use it for file explorers, nested category browsers, or any
interface that visualizes parent-child relationships.

## When to reach for it / when not to

- **Do:** Provide meaningful labels and icons for each node to make the hierarchy
  easy to scan.
- **Do:** Pre-expand important branches so users see key content immediately.
- **Do:** Leaf rows reserve space for a chevron column whenever the tree has any
  expandable item to line up under; only a fully flat tree (no expandable
  items at all) renders its rows flush. Rely on this rather than nudging
  indentation with custom CSS.
- **Don't:** Nest more than 4–5 levels deep; flatten the structure or use a different
  pattern.
- **Don't:** Use a tree for flat, non-hierarchical data; use a List instead.

## Props

| prop | type | required | default | meaning |
| --- | --- | --- | --- | --- |
| `items` | `TreeListItemData[]` | yes | `` | Tree items as a recursive data structure. Each item can have nested `children` arrays. / |
| `density` | `TreeListDensity` | no | `'balanced' /` | Spacing density for tree list items. - 'compact': Tighter spacing for dense UIs - 'balanced': Standard spacing - 'spacious': Extra spacing for readability |
| `variant` | `TreeListVariant` | no | `'lineGuides' /` | Visual treatment of the hierarchy guide (connector) lines. - `lineGuides`: connector lines between parent and child rows - `noGuides`: no connector lines; indentation alone conveys nesting Orthogonal to `density` (which controls spacing) — the two compose. |
| `header` | `ReactNode 'data-testid'?: string` | no | `` | Header content rendered above the tree list. Semantically associated via aria-labelledby. / |

## Anatomy

- `Tree list` (required) — Container that presents the hierarchical tree.
- `Header` (optional) — Caller-provided content that visibly names the tree.
- `Item` (required) — Painted row for one node in the hierarchy.
- `Chevron` (optional) — Expand and collapse control rendered for an Item with children.
- `Chevron glyph` (optional) — Directional symbol rendered by Icon inside a Chevron.
- `Item label` (required) — Primary content that identifies an Item.
- `Item description` (optional) — Secondary text rendered below an Item label.
- `Start content` (optional) — Caller-provided content rendered before an Item label.
- `End content` (optional) — Caller-provided content rendered after an Item label.
- `Guide` (optional) — Connector line that shows parent-child relationships.
