# Timer

**Category:** Content  |  **Group:** -  |  **Port status:** not started

Displays a standardized elapsed duration for active work without scheduling
a React render on every tick. Elapsed format updates by second below one
hour and by minute after one hour; clock format remains second-precise.

## When to reach for it / when not to

- **Do:** Use elapsed for compact duration text that may span seconds, minutes, or
  hours.
- **Do:** Use clock for stopwatch-like surfaces where seconds remain meaningful
  after an hour.
- **Do:** Pass startTime when the operation began before Timer mounted so the
  display reflects the complete wait.
- **Don't:** Do not use Timer for dates, time zones, or relative calendar language;
  use Timestamp instead.
- **Don't:** Do not add aria-live unless hearing an announcement every tick is
  appropriate for the specific task.

| `type` | `'body' \| 'large' \| 'label' \| 'supporting' \| 'code' \| 'display-1' \| 'display-2' \| 'display-3' \| 'inherit'` | no | `'supporting'` | Semantic text type. Uses the same typography behavior as Timestamp. |

| `color` | `'primary' \| 'secondary' \| 'disabled' \| 'placeholder' \| 'accent' \| 'inherit'` | no | `'secondary'` | Text color. |
| `weight` | `'normal' \| 'medium' \| 'semibold' \| 'bold'` | no | `` | Font weight override. |
| `xstyle` | `StyleXStyles` | no | `` | StyleX styles for the Text wrapper. Must be a stylex.create() value. |
