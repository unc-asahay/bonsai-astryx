# Grid

**Category:** Layout  |  **Group:** Layout  |  **Port status:** not started

A CSS grid layout container for arranging children in rows and columns. Use
Grid for card galleries, dashboards, and any multi-column layout. For
columns that reflow on small screens, use `columns={{minWidth, max}}`; a
numeric `columns` is exactly N columns at every width and never reflows.

## When to reach for it / when not to

- **Do:** Default to responsive columns for anything that must survive a phone:
  `columns={{minWidth: 240, max: 4}}` renders at most 4 columns, each at
  least 240px, and drops to one full-width column when narrow.
- **Don't:** Use `columns={4}` for a row that must work on small screens; a number
  never reflows and renders four narrow tracks on a phone. Reserve numbers
  for rows that must stay fixed, such as a 7-day week.
- **Do:** Always pair `minWidth` with `max`: `max` caps the count on wide screens
  and lets the last column shrink to a narrow container; `{minWidth}`
  alone overflows a phone narrower than `minWidth`.
- **Do:** Use `repeat: 'fill'` (the default) for consistent item widths. Use
  `'fit'` when items should stretch to fill leftover space.
- **Don't:** Write manual CSS grid; Grid handles spacing and responsive behavior for
  you.
- **Don't:** Use `HStack` with wrapping for grids; use Grid instead.
- **Do:** Track templates use CSS-variable indirection (not raw inline styles), so
  `xstyle` overrides of `gridTemplateColumns` (including inside `@media`
  queries) take effect.

## Props

| prop | type | required | default | meaning |
| --- | --- | --- | --- | --- |
| `columns` | `number \| {minWidth: number, max?: number, repeat?: 'fill' \| 'fit'}` | no | `` | Column configuration. A number is exactly N equal columns at every width and never reflows (e.g. `columns={3}`); for columns that reflow on small screens, use `{minWidth, max}`. Use an object for responsive columns: `minWidth` sets the minimum column width in px, `repeat` controls track behavior (`"fill"` preserves empty tracks for consistent widths, `"fit"` collapses empty tracks so items stretch; defaults to `"fill"`), and `max` caps the maximum number of columns. |
| `width` | `SizeValue` | no | `` | Container width. Numbers are treated as pixels, strings are used as-is. |
| `height` | `SizeValue` | no | `` | Container height. Numbers are treated as pixels, strings are used as-is. |
| `maxWidth` | `SizeValue` | no | `` | Maximum container width. Numbers are treated as pixels, strings are used as-is. |
| `minHeight` | `SizeValue` | no | `` | Minimum container height. Numbers are treated as pixels, strings are used as-is. |
| `gap` | `0 \| 0.5 \| 1 \| 1.5 \| 2 \| 3 \| 4 \| 5 \| 6 \| 8 \| 10` | no | `` | Spacing between all items. |
| `rowGap` | `0 \| 0.5 \| 1 \| 1.5 \| 2 \| 3 \| 4 \| 5 \| 6 \| 8 \| 10` | no | `` | Row spacing; overrides `gap` for the row axis. |
| `columnGap` | `0 \| 0.5 \| 1 \| 1.5 \| 2 \| 3 \| 4 \| 5 \| 6 \| 8 \| 10` | no | `` | Column spacing; overrides `gap` for the column axis. |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch'` | no | `'stretch'` | Vertical alignment of items. |
| `justify` | `'start' \| 'center' \| 'end' \| 'stretch'` | no | `'stretch'` | Horizontal alignment of items. |
| `children` | `ReactNode` | no | `` | Grid content. |
| `xstyle` | `StyleXStyles` | no | `` | StyleX styles for layout customization (margins, positioning, sizing). Must be a stylex.create() value: not an inline style object like style={{}}. |

## Anatomy

- `Grid container` (required) — Two-dimensional layout container that arranges caller-supplied items in rows and columns.
- `Spanning item` (optional) — Optional GridSpan wrapper that changes one item's column or row participation.
