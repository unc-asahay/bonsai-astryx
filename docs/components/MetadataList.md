# MetadataList

**Category:** Table & List  |  **Group:** MetadataList  |  **Port status:** not started

MetadataList displays key-value pairs for object attributes like quality,
condition, and status, in a structured layout. Use it for detail panels,
settings summaries, and record information.

## When to reach for it / when not to

- **Do:** Choose label position based on content: "start" for short values, "top"
  for long or complex values.
- **Do:** Collapse long lists with `maxNumOfItems` to keep the page scannable.
- **Don't:** Use for extensive form input; use a form layout instead.
- **Don't:** Use for data that doesn't have a clear key-value structure.

## Anatomy

- `Title` (optional) — Optional title for the metadata list.
- `Label` (required) — The key label for each metadata entry.
- `Metadata` (required) — The value displayed in various formats.
- `Disclosure` (optional) — Collapse/expand control for the list.
