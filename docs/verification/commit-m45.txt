M45: List - the list primitive (List_container)

Port upstream List/List.tsx + ListHeader.tsx + ListItem.tsx as Astryx.List_container
(a role=list decorator for ul/ol) with rows built by Astryx.List_item (an Item
composed with as_:Li plus a marker span). Density (spacious/comfortable/compact),
dividers (inherited row-border rule), CSS-counter numbering with start, custom
counter markers, header + description paired to the list through aria-labelledby
with generated ids, horizontal scrolling, edge alignment.

"List" here — the library is effectively unwrapped, so a top-level List shadows
Stdlib/Core for every linked unit (src/list.ml -> dependency cycle Vstack ->
Common -> List -> Common plus List.fold errors; the alias-only variant -> Unbound
value List.fold). Public path: Astryx.List_container.
